녹화 전 확인 (낭독하지 않음)
- 저장소 루트에서 python game/code/main.py 실행. VS Code에서 pico2d가 설치된 Python 환경을 선택한다.
- 입장하는 전투 맵이 달라질 수 있다. 리허설에서 빨간 출발구 가까운 배치 가능 지상 칸과 적이 오는 방향을 확인한다. 접근이 늦으면 출발구에 더 가까운 칸을 고른다.
- 슬라이드와 게임 창 전환을 미리 연습한다. 녹화본을 직접 재생해 1분 30초 길이, 글자 크기, 음성 선명도를 확인한다.
- 발표 PPT는 프로젝트 저장소에 포함한다. 새 YouTube 영상 링크와 프로젝트 GitHub 저장소 링크를 e-class에 제출한다. 가이드상 마감은 발표 당일 00:01이다.
