# 궁수 공격 v2 참고

사용자가 지정한 [소은설의 「Archetto Skin!!」 영상](https://www.youtube.com/watch?v=RM3RW9ugnj0)을 실제 브라우저에서 열어 일시 정지하고 프레임 단위로 확인했다. 첫 스킬 구간 중 7.26~8.61초에서 13개 시점을 관찰했다. 아래 시간은 영상 재생기의 관찰 시점이며 동작 경계의 정확한 타임코드는 아니다.

| 관찰 시점 | 확인한 움직임 | 적용 |
| --- | --- | --- |
| 7.54초 | 뻗은 활 팔은 유지되고 손·표정이 정리됨 | 발사 직후 활을 과하게 흔들지 않음 |
| 7.68~7.81초 | 활을 낮추고 팔을 몸 앞으로 접음 | 준비·복귀 자세에 실제 팔 모양 변화 |
| 7.94초 | 활을 다시 세우며 화살을 준비 | 00~02 준비 |
| 8.08초 | 활 팔을 뻗고 시위 손을 가슴·옷깃 쪽으로 당김 | 03~06 당기기·조준 |
| 8.21초 | 빠른 발사 효과와 놓는 손 | 07에서 손을 펴고 화살 이동 |
| 8.34~8.61초 | 몸이 정리된 뒤 머리카락과 장식이 늦게 흔들림 | 머리·묶은 머리의 작은 시차 |

기존 버전의 문제는 원본 자세와 맞지 않는 어깨·손 위치, 몸통과 겹치는 여러 팔 조각, 얼굴 앞으로 그려진 시위와 낮은 완성도였다. v2는 기존 궁수 디자인을 참고한 연결된 상체 16장을 사용한다. 원본 머리·머리카락·다리·화살통을 따로 합성하며 프레임 전체를 새 캐릭터 그림으로 교체하지 않는다.

참고 영상의 캐릭터 의상·머리·귀·기계식 활과 스킬 이펙트를 게임 리소스로 사용하지 않았다. 참고한 것은 동작 순서, 활 팔을 안정시키는 방식, 빠른 발사와 후속 반응이다. 최종 게임용 시간은 방향별 16장·16FPS·1초로 정리했다.
